RESTful 接口文档

基础路径：{{ api_prefix }}，返回格式统一为 {"status": <HTTP状态码>, "message": "OK", "data": {...}}。

数据以 Teamcenter 风格的 UID 标识（如 item-p1000、bl-p1000-1）， 可用物料编号查询后获取 UID，再查询 BOM 结构。

接口一览

方法路径说明主要参数
GET{{ api_prefix }}/health健康检查-
GET{{ api_prefix }}/items物料列表 / 搜索item_id, q, item_type, project, status, limit, offset
POST{{ api_prefix }}/items创建物料（测试用）JSON body
GET{{ api_prefix }}/items/<uid>物料详情-
GET{{ api_prefix }}/items/<uid>/revisions物料版本列表-
GET{{ api_prefix }}/items/<uid>/revisions/<rev_uid>版本详情-
GET{{ api_prefix }}/items/<uid>/bomBOM 结构（单层）depth=0 默认，depth=-1 全展开
GET{{ api_prefix }}/items/<uid>/bom/expandBOM 全展开（多层）-
GET{{ api_prefix }}/structures/<item_uid>BOM 结构别名接口depth=0 默认
GET{{ api_prefix }}/bomlines/<uid>BOM 行详情-
GET{{ api_prefix }}/bomlines/<uid>/childrenBOM 行的子行depth=0 默认

示例

1. 搜索物料

curl "{{ api_prefix }}/items?q=变速箱"

2. 查询单层 BOM

curl "{{ api_prefix }}/items/item-p1000/bom?depth=0"

3. 查询完整 BOM（多级展开）

curl "{{ api_prefix }}/items/item-p1000/bom/expand"

4. 按物料编号直接获取 BOM

curl "{{ api_prefix }}/structures/item-p1000?depth=-1"

5. 创建物料

curl -X POST "{{ api_prefix }}/items" -H "Content-Type: application/json" -d '{
  "item_id": "TEST-001",
  "item_name": "测试零件",
  "item_type": "Part",
  "project": "XM-MOCK",
  "revision_id": "A"
}'
