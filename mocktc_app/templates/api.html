RESTful 接口文档

基础路径：{{ api_prefix }}，返回格式统一为 {"status": <HTTP状态码>, "message": "OK", "data": {...}}。

数据以 Teamcenter 风格的 UID 标识（如 item-p1000、bl-p1000-1）， 可用物料编号查询后获取 UID，再查询 BOM 结构。

特殊接口：物料 LITHO-001（光刻机整机）的 BOM 直接返回外部上传的原始 JSON 文件 20260808-bom1-2.json（3316 行，不做包装， 顶层为数组，字段含 bom_level / parent_uid / child_uid / part_id / part_name / quantity）。

只读查询接口：{{ api_prefix }}/fixtures* 提供同一文件的列表、完整读取与按物料查询，返回统一包装的结构化 JSON； 未知 fixture / 物料返回 404，非法参数返回 400，防目录穿越。

示例

1. 搜索物料

curl "{{ api_prefix }}/items?q=变速箱"

2. 查询单层 BOM

curl "{{ api_prefix }}/items/item-p1000/bom?depth=0"

3. 查询完整 BOM（多级展开）

curl "{{ api_prefix }}/items/item-p1000/bom/expand"

4. 按物料编号直接获取 BOM

curl "{{ api_prefix }}/structures/item-p1000?depth=-1"

5. 创建物料

curl -X POST "{{ api_prefix }}/items" -H "Content-Type: application/json" -d '{
  "item_id": "TEST-001",
  "item_name": "测试零件",
  "item_type": "Part",
  "project": "XM-MOCK",
  "revision_id": "A"
}'

6. 外部 BOM 数据（LITHO-001，返回 20260808-bom1-2.json 原始内容）

curl "{{ api_prefix }}/items/item-litho-001/bom/expand"

7. 查看可用 fixture 列表

curl "{{ api_prefix }}/fixtures"

8. 按物料编号查询（精确匹配，附带父级信息）

curl "{{ api_prefix }}/fixtures/20260808-bom1-2.json/query?part_id=S01&exact=1"

9. 完整读取 fixture（结构化）

curl "{{ api_prefix }}/fixtures/20260808-bom1-2.json"

10. 物料详情（不存在返回 404）

curl "{{ api_prefix }}/fixtures/20260808-bom1-2.json/materials/S01"
